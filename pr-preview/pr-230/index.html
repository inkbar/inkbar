One PDF editor. Four ways to build it.

Each sandbox runs the same viewer on a tour of every annotation, built with a different binding. Highlight text, mark it for redaction, leave notes, or open a PDF of your own.

Files stay in your browser. Nothing is uploaded.

Pick your stack

  • React @inkbar/react

    Components and hooks for React 19.

    $pnpm add @inkbar/react Open the sandbox for React
  • Vue @inkbar/vue

    Components and composables for Vue 3.

    $pnpm add @inkbar/vue Open the sandbox for Vue
  • Svelte @inkbar/svelte

    Components for Svelte 5, built on runes.

    $pnpm add @inkbar/svelte Open the sandbox for Svelte
  • TypeScript @inkbar/core/dom

    No framework. createViewer renders the viewer, toolbar and popovers into any element.

    $pnpm add @inkbar/core Open the sandbox for TypeScript

Every binding also needs @inkbar/core and @inkbar/theme. The quickstart has the full install.

What to try

  • Highlight

    Pick the highlighter and drag across a line of text.

  • Redact

    Mark names, numbers or whole regions for removal.

  • Leave a note

    Pin a comment anywhere on the page, then reply to it.

  • Make it your own

    Inkbar has a plugin system for adding your own tools and commands.
