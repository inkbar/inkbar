# Inkbar

Browser PDF viewer and editor for Vue, built on PDF.js. Headless primitives, typed annotations, one coordinate system.

Made by [Redactr](https://redactr.io).

## Packages

| Package         | Purpose                                                      |
| --------------- | ------------------------------------------------------------ |
| `@inkbar/core`  | Document model, rendering, annotations, tools. No framework. |
| `@inkbar/vue`   | Vue 3 components and composables.                            |
| `@inkbar/theme` | Default stylesheet using shadcn token names.                 |

## Development

```sh
pnpm install
pnpm build
pnpm test
```
