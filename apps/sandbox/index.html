inkbar GitHub

One PDF editor. Four ways to build it.

Each page runs the same viewer on a sample case file. Highlight text, mark it for redaction, leave notes, run Suggest redactions, or open a PDF of your own. Files stay in your browser.

  • React

    Components and hooks for React 19.

    pnpm add @inkbar/react @inkbar/core @inkbar/theme

  • Vue

    Components and composables for Vue 3.

    pnpm add @inkbar/vue @inkbar/core @inkbar/theme

  • Svelte

    Components and hooks for Svelte 5.

    pnpm add @inkbar/svelte @inkbar/core @inkbar/theme

  • TypeScript

    No framework. createViewer from @inkbar/core/dom renders the viewer, toolbar and popovers.

    pnpm add @inkbar/core @inkbar/theme

From the team behind Redactr. Docs at inkbar.dev.
